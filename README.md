# Welcome to HandyCart: A Delivery App (Food and Groceries) for People qith Disabilities 👋

This is an [Expo](https://expo.dev) project created with [`create-expo-app`](https://www.npmjs.com/package/create-expo-app).

## accessible, inclusive, and user-friendly!! (built for both iOS and Android)

The core features of the app:
• Emergency Contact/SOS Alert System
• Colorblind-friendly Design
• Text-to-Speech and Speech-to-Text Integration
• Easy Ordering with Accessibility in mind

## Additional Features:
• Haptic Feedback Integration
• Favorites & Repeat Order Function
• Custom Delivery Instructions (with audio option)
• Delivery Partner Accessibility Training
